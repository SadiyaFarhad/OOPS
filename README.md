# OOPS
Object-Oriented Programming (OOP) is a coding approach using "objects" that contain data and methods. Its core principles are:

Encapsulation: Keeping data and methods together and protected.
Abstraction: Hiding complex details and focusing on main features.
Inheritance: Reusing code by creating new classes from existing ones.
Polymorphism: Allowing different classes to be used interchangeably.
OOP promotes modular, reusable, and organized code.
